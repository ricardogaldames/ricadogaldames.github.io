Entrelazadas - Tejidos Artesanales 🧶
Bienvenido al repositorio de la plataforma web de Entrelazadas, un emprendimiento dedicado a la creación de productos únicos tejidos a mano. Este proyecto combina la calidez de lo artesanal con una interfaz moderna y funcional.

✨ Sobre el Proyecto
Entrelazadas es un negocio real que transforma lana en piezas con historia. La web fue diseñada para exhibir su catálogo de productos, que incluye:

Bolsos: Diseños resistentes y con estilo.
Muñecos (Amigurumis): Compañeros tejidos con amor para todas las edades.
Neceseres: Organizadores prácticos con texturas únicas.
El objetivo principal de este sitio es brindar una vitrina digital profesional, optimizada para dispositivos móviles y con una navegación intuitiva.

🛠️ Tecnologías Utilizadas
Para el desarrollo de esta plataforma se utilizaron las siguientes herramientas:

HTML5: Estructura semántica del contenido.
CSS3: Estilos personalizados, tipografías y paleta de colores acorde a la marca.
Bootstrap 5: Framework para garantizar un diseño responsive (adaptable a celulares y tablets) y componentes ágiles.
JavaScript: Lógica de interacción, como validación de formularios, filtros de productos o animaciones simples.

🚀 Características Principales
Diseño Responsive: La web se ve perfecta en cualquier tamaño de pantalla gracias a la rejilla de Bootstrap.

Galería de Productos: Sección visual detallada con los bolsos, muñecos y neceseres.
Sección "Sobre Nosotros": Espacio dedicado a la historia del emprendimiento y el valor del trabajo manual.
Formulario de Contacto: Conexión directa para pedidos personalizados o consultas.
Interactividad: Uso de Java (Script) para mejorar la experiencia del usuario.

📝 Notas del Desarrollador
Este trabajo fue realizado enfocándose en la experiencia de usuario (UX) y la identidad visual. Se prestó especial atención a que los colores y la disposición de los elementos transmitieran la suavidad y el detalle propios del tejido a mano.
